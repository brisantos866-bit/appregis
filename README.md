# Registro y Carnet Digital - Solo para Honduras

Este es un sistema web desarrollado en Flask (Python) para el registro de colaboradores y la generación automática de un **Carnet Digital** con código QR.

## 🚀 Características
- Formulario de registro con validación de datos (Honduras).
- Captura de fotografía en vivo usando la cámara web o subida desde archivo.
- Generación de un token único para cada usuario.
- Carnet digital público accesible mediante QR o enlace directo.
- Base de datos local SQLite.

## 🛠️ Tecnologías
- Python 3
- Flask
- SQLite
- Bootstrap 5
- qrcode

## 🌐 Despliegue
El proyecto está desplegado en Render.
